# RunixMU S6E3 Open Source

Open source кодовая база Mu Online Season 6 Episode 3 (сервер + клиент + инструменты), ориентированная на стабильность, прозрачную разработку и воспроизводимые конфигурации.

## Цели проекта

- Поддерживать стабильный S6E3 стек без контента из поздних сезонов
- Делать изменения конфиг-ориентированными и безопасными для production
- Упростить сопровождение через открытый процесс разработки на GitHub
- Снизить порог входа для новых контрибьюторов

## Состав репозитория

- `GameServer/` — игровой сервер
- `DataServer/` — хранилище игровых данных
- `JoinServer/` — авторизация и сессии
- `ConnectServer/` — сервер подключений
- `Main5.2/` — клиентская часть
- `Launcher/` — лаунчер
- `UpdaterService/` — сервис обновлений
- `Tools/` — вспомогательные утилиты

## Технологии

- C++ (Visual Studio toolchain)
- MSSQL
- XML/TXT/INI конфиги
- Node.js (для `UpdaterService`)

## Быстрый старт

1. Клонируйте репозиторий
2. Откройте нужный `.sln` в Visual Studio
3. Настройте строки подключения к MSSQL для серверных компонентов
4. Проверьте игровые конфиги в соответствующих `Data` директориях
5. Соберите и запустите сервисы в порядке: Data/Join/Connect/Game

## Open Source процесс

- Ошибки и запросы функций: GitHub Issues
- Изменения: Pull Request в `main`
- Стиль изменений: небольшие и атомарные PR
- Перед PR: убедитесь, что сборка проходит локально
