# Contributing

Спасибо за вклад в RunixMU.

## Как предложить изменение

1. Создайте issue с описанием проблемы или идеи
2. Сделайте fork и отдельную ветку
3. Внесите атомарные изменения
4. Проверьте локальную сборку изменённых компонентов
5. Откройте Pull Request с понятным описанием

## Требования к изменениям

- Сохраняйте совместимость с Mu Online S6E3
- Не добавляйте контент из более поздних сезонов
- Предпочитайте конфиг-ориентированные изменения
- Не коммитьте секреты, пароли, ключи и приватные дампы БД
- Описывайте миграции конфигов и SQL-изменения в PR

## Стандарт PR

- Один PR = одна логическая задача
- Добавьте шаги для ручной проверки
- Приложите скриншоты или логи, если есть UI/рантайм-изменения
- Укажите возможные риски и план отката

## Сообщения коммитов

Рекомендуемый формат:

`type(scope): краткое описание`

Примеры:

- `fix(gameserver): validate move gate range`
- `feat(config): add xml schema check for itemdrop`
