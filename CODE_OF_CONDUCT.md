# Code of Conduct

## Наши принципы

Мы поддерживаем открытое и уважительное сообщество для всех участников независимо от опыта, возраста, пола, внешности, национальности, религии и уровня подготовки.

## Ожидаемое поведение

- Уважительное общение по существу
- Конструктивная обратная связь
- Готовность исправлять ошибки
- Поддержка новичков и прозрачность решений

## Недопустимое поведение

- Оскорбления, угрозы, травля
- Публикация персональных данных без согласия
- Спам, троллинг, намеренный саботаж обсуждений
- Любые формы дискриминации

## Модерация

Поддерживающие репозиторий вправе удалять, редактировать или отклонять сообщения и вклад, нарушающие эти правила.

## Сообщить о нарушении

Создайте приватное обращение через контакт из `SECURITY.md` с темой `Code of Conduct`.
