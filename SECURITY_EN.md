# Security Policy

## Supported Branches

- `main` — actively supported

## Reporting a Vulnerability

Do not disclose vulnerabilities in public issues.

Send a private report with subject `Security Report` and include:

- Short vulnerability description
- Affected component and files
- Reproduction steps
- Impact assessment
- Possible fix or mitigation

Before a fix is published, please follow coordinated disclosure.

## What Happens After a Report

1. Report acknowledgement
2. Initial triage and prioritization
3. Fix implementation and verification
4. Patch publication and notification
